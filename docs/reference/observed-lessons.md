# Наблюдения: уроки на the reference sim

Что видно в оригинале (скриншоты пользователя, 2026-10-04). Это описание **механики**: тексты, иконки,
маскот и названия не копируем, пишем свои.

## Экран «Уроки»
- Шапка: навигация (Play / Gear / Shop / Settings), карточка профиля: ник, уровень, XP-бар `66 / 200 XP`, кредиты.
- Курсы вкладками: «First Flight 1/7», «Banking 0/7» (прогресс курса в заголовке).
- Сетка карточек урока: номер, схематичная иконка манёвра, название, прогресс-бар, статус
  («Completed» с галочкой / «To fly»). Выбранная карточка подсвечена.
- Левая панель выбранного урока: крупный номер, иконка, название, одна строка задания, кнопка «Start lesson».
- Курс 1 по смыслу: взлёт → полёт вперёд → угол наклона → держать линию → держать высоту → менять высоту → итоговый маршрут.
  Курс 2 — виражи (крен).

## Структура урока
1. **Шаги** (у первых двух уроков по 2). Плашка вверху слева: «Лётная школа · Шаг N / M», название, ссылка «← Уроки».
2. Внутри шага: **реплики инструктора** по одной, переход по клику. Маскот слева (меняет позу), пузырь по центру снизу.
3. Параллельно идёт **демо-полёт** (FPV-камера записанного полёта инструктора). Демо может повторяться
   («сейчас повторю, смотри на высоту»).
4. Справа внизу **контур пульта**, точки стиков двигаются по записанным стикам демо.
5. **Практика**: пузырь с заданием (без «клика»), HUD скорость (км/ч) и высота (м), прицел-горизонт,
   цели (ворота: кольцо или рамка, может быть наклонной; посадочная площадка). Цель подсвечена цветом.
6. За ворота всплывает «+10 flight XP».
7. **Экран завершения**: XP за визит (полёт + бонус), прогресс до следующего дрона, кредиты,
   тост ачивки, кнопки: следующий урок / ещё раз / все уроки / меню. Сверху полоса уровня.

## Выводы для нас
- Урок = данные: шаги [реплики + демо-запись + камера] + практика [цели]. Это прямо ложится на редактор уроков.
- Демо-полёт = запись поз и стиков, проигрываемая с интерполяцией (нужен recorder/player рано).
- Пройти урок 2 с клавиатуры тяжело: нужен мягкий режим клавиатуры (сглаживание, ограничение наклона
  или помощь по высоте для новичков), иначе игрок застревает на втором уроке.

## Падение в практике
- Если дрон упал и не может взлететь (перевёрнут), по центру появляется карточка «Нажми [R] чтобы респавниться».
- Урок не сбрасывается: пузырь с заданием и HUD остаются, после R практика продолжается со спавна.
- Отдельного экрана провала нет.

## Пока не известно
- Что происходит при промахе мимо ворот (вероятно, ничего: просто лететь снова).
- Блокируются ли стики в уроках («только левый стик» звучит как просьба, не блок).
- Как выглядит редактор уроков (вероятно, только для админов) — ждём ответа заказчика.
